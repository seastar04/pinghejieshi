# 平和界世·坐一会

一个温暖、安静的小网页：在森林、河流与木屋之间休息一下，写下今日心情。
使用 HTML、CSS 和原生 JavaScript，无需安装依赖，无需数据库或 API。

## 四个文件分别做什么？

- `index.html`：网页的内容和结构，包含标题、欢迎文字、按钮与心情输入框。
- `style.css`：网页的外观，包含颜色、排版、本地森林木屋图片的显示与裁切，以及手机屏幕适配。
- `script.js`：网页的交互，负责显示欢迎文字、保存心情和下次打开时恢复记录。
- `README.md`：项目说明书，记录预览、检查与提交方法。

## 如何预览

最简单的方法：将仓库下载或克隆到自己的电脑，双击 `index.html`，用现代浏览器打开。四个文件需要放在同一文件夹，并保留 `assets` 图片文件夹。

推荐使用本地网页服务，以获得更稳定的本地存储行为。如果已安装 Python，在项目文件夹打开终端运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 也可以使用 `py -m http.server 8000 --bind 127.0.0.1`。
然后在同一台电脑的浏览器地址栏输入 `http://127.0.0.1:8000`。按 `Ctrl+C` 停止服务。
云环境中的地址只供环境内部检查；要在自己的电脑预览，请先下载或克隆项目，再运行以上命令。

## 心情记录与隐私

- 点击「保存心情」后，内容存入当前浏览器的 `localStorage`，不上传服务器。
- 再次打开相同地址，可以恢复上次保存的内容；继续编辑后需要再次点击保存。
- 保存空白内容可以清空旧记录。
- 不同设备、浏览器、网址或端口不会共享记录；直接打开文件时，存储行为取决于浏览器。
- 清除浏览器数据会删除记录。隐私模式或禁用本地存储时，保存可能失败，页面会提示。
- 使用同一浏览器的人可能看见记录，因此请谨慎在公共设备上保存私人内容。

## 如何检查

如果已安装 Node.js，可以检查 JavaScript 语法：

```sh
node --check script.js
```

在浏览器中检查：

1. 点击「坐一会」，应出现「你可以在这里休息一会。不需要证明什么，也不需要急着变好。」。
2. 输入中文心情并保存，刷新页面，应恢复相同内容。
3. 清空输入框并保存，刷新页面，应保持空白。
4. 缩小窗口或使用手机，确认文字、输入框和按钮清楚可用。

项目没有构建步骤，也不需要 `npm install`。

## 如何提交到 GitHub

在项目文件夹中打开终端，依次运行：

```sh
git status
git diff
git add index.html style.css script.js README.md
git commit -m "创建平和界世·坐一会网页"
git push origin main
```

`git status` 查看改动，`git diff` 查看具体内容，`git add` 选择要提交的文件，`git commit` 在本地保存一个版本，`git push` 将版本上传到 GitHub。
如果使用其他分支，把最后的 `main` 换成当前分支名称（可运行 `git branch --show-current` 查看）。
推送需要你拥有仓库写入权限。若电脑提示认证，请使用 GitHub 支持的登录方式，不要把密码或令牌写入网页文件。

## 首页森林木屋图片

- 本地资源：`assets/forest-cabin.png`。此图由 OpenAI 图像生成工具为本项目生成，为写实风格的 AI 画面，并非实景摄影；没有使用第三方图库照片或图片热链。
- 图片通过 `object-fit: cover` 填满原来的圆角画框，电脑与手机保持原有布局。
- 如需替换为自己的照片，请使用自己拍摄或获得网站使用授权的图片，放入 `assets` 文件夹，再修改 `index.html` 中图片的 `src`、尺寸和 `alt` 描述。建议选用竖幅图片，并记录来源、作者及许可条件。
